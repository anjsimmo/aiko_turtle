aiko.hashtag.ai

Welcome. This server hosts a community MQTT broker and the Aiko Services “shared services” (Registrar, HyperSpace and ChatServer) for the Melbourne AI+ML+Robots community, so members can experiment with distributed robots and agents without running their own infrastructure.

It is hosted by Angie on Google Cloud as a volunteer effort. Please treat it as a hobby and community sandbox: there are no uptime promises, and you should not send any private data to it.

Connect

export AIKO_MQTT_HOST=aiko.hashtag.ai

aiko_registrar list
aiko_dashboard

mosquitto_sub -h aiko.hashtag.ai -t 'aiko/#' -v

The last command lets you watch the traffic. The broker is open, with no username or password. The ProcessManager runs in safe mode, so you can list services but not start or stop them.

Open source, with thanks

Aiko Services is open source: github.com/geekscape/aiko_services, along with Aiko Chat at github.com/geekscape/aiko_chat. Aiko has been developed over years by Andy Gelme, who leads the AI+ML+Robots group; the group's study sessions are where it is being put to work on real robots. This server just gives that work a place to play.
